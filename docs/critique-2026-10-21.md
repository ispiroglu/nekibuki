## What is genuinely good

- **Zero noise.** 0 console errors, 0 page errors, 0 failed requests and 0 horizontal
  overflow across 74 route × viewport × theme states.
- **The annotation dialog is correct**: initial focus, Tab trap, body scroll lock,
  Escape, focus restored to the marker that opened it.
- **Off-screen deck panels are genuinely inert** (`inert` + `aria-hidden`), and the
  delete dialog lands focus on **Cancel** by default.
- **Reduced motion is honoured where it matters** — the scan line and breathing ring are
  not rendered, yet every state change still happens and stays visible.
- **Dark mode is composed, not inverted**: paper/surface/muted-ink are re-mapped,
  `--brand-ink` lifts to `#7fc7bb` (8.55:1), and the `theme-color` metas are correct in
  all three appearance states.
- **Token discipline holds.** Every surface resolves from the semantic set; `?brand=`
  presets keep all four brand roles populated and the default stays petrol.
- **Failure copy is specific and actionable** — camera permission, analysis failure,
  history load failure, and every empty state names the next action.
- **The report column is a composed editorial surface**: photo → title → lede → quick
  facts → trivia → numbered references, with the photo the only colourful thing on screen.

  320 px phone, the shutter becomes an oval, and the "Places you looked at" button is

- **Casey (distracted, one-handed, outdoors)** — the settings shelf is unreachable
  without a gesture nobody expects; the guide's load-bearing prose is the smallest text
  on the page (14 px, 26 ch per line at 320); the report title is behind a chat bar in
  landscape; the send button is the only affordance that disappears at night.
- **Jordan (first-timer)** — "Terms and Privacy Policy" points at nothing; the camera
  gives no framing guide and no persistent instruction; tapping a photo dot produces the
  same sentence as scrolling.
- **Riley (stress tester)** — deep-linking a guide on a cold profile lands on "This
  guide is gone"; the shipped demo data makes the saved-only empty state unreachable;
  the Profile panel cannot be swiped.

## Method, limits and follow-ups

- **Dual assessment honoured.** The five design reviews (A) and the evidence pass (B)
  ran in isolated workers with no visibility of each other's output; B was instructed not
  to score. The coordinator synthesised after reading all six.
- **Scored on the current build**, not as a before/after delta — there is no baseline
  critique to compare against. This is the first scored pass on this codebase.
- **The Impeccable CLI in this environment has no `critique-storage` command**, so no
  snapshot was persisted to `.impeccable/`. A future run should compare against this
  document instead.
- **Untested by anyone:** real-device touch (all touch results are emulated via CDP
  `Input.dispatchTouchEvent`), iOS Safari, the real vision provider (the mock served
  every analysis), the service worker and offline installability (`devOptions` off in
  dev), production bundle size and LCP/INP, and HUD legibility over real photography
  (the camera was Chrome's fake solid-green device).
- **Detector caveat:** `impeccable detect` in text mode aborts on a URL
  ("Protocol error: connection closed"); only JSON mode worked, and the source scan is
  regex-only, so its 0 is an undercount rather than a pass.
